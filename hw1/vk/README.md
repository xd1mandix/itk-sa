# Описание ключевых систем IT-ландшафта VK

## 1. Клиент

| Поле                        | Значение                                                                                                                                                                                                                                                                            |
| :-------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | Клиент                                                                                                                                                                                                                                                                              |
| **Категория**               | System of Engagement (SoE)                                                                                                                                                                                                                                                          |
| **Роль в бизнесе**          | Пользовательский интерфейс, через который человек просматривает контент и взаимодействует с продуктами VK. На диаграмме это обобщённый клиентский блок; в реальной архитектуре веб-клиент, мобильные приложения и отдельные продуктовые интерфейсы могут быть разными приложениями. |
| **Входящие потоки данных**  | Результаты вычислений рекомендательных систем                                                                                                                                                                                                                                       |
| **Исходящие потоки данных** | CDN, Сервис Авторизации, Медиа-запросы через балансировщики, запись данных в MDM, отправка статистики в DWH                                                                                                                                                                         |

## 2. Auth Service

| Поле                        | Значение                                                                                                                                                                                                                                                                                                          |
| :-------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | Auth Service                                                                                                                                                                                                                                                                                                      |
| **Категория**               | System of Record (SoR) для учётных данных и/или сессий — только если именно этот сервис является их авторитетным владельцем; иначе инфраструктурный сервис безопасности                                                                                                                                           |
| **Роль в бизнесе**          | Выполняет аутентификацию пользователя и участвует в выдаче или проверке удостоверяющих данных доступа. На схеме показан как отдельный сервис входа. Нельзя без подтверждения утверждать, что он хранит пароли, профили и все данные авторизации: эти функции могут быть разделены между несколькими компонентами. |
| **Входящие потоки данных**  | Запросы на вход от клиента; учётные данные или токены; запросы на проверку или обновление сессии.                                                                                                                                                                                                                 |
| **Исходящие потоки данных** | Результат аутентификации, токен или состояние сессии клиенту; сведения о пользователе или правах доступа внутренним сервисам, если предусмотрена такая интеграция; события безопасности в журналы и системы мониторинга, если они подключены.                                                                     |

## 3. MDM

| Поле                        | Значение                                                                                                                                                                              |
| :-------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Название системы**        | MDM (Master Data Management)                                                                                                                                                          |
| **Категория**               | System of Record (SoR) для тех мастер-данных, которыми система действительно владеет                                                                                                  |
| **Роль в бизнесе**          | MDM выступает источником данных, передаваемых в Key-Value Storage / Tarantool для быстрого доступа. Это могут быть справочники, сведения о продуктах или другие согласованные записи. |
| **Входящие потоки данных**  | Записи и изменения из систем-источников; запросы на создание или обновление мастер-данных.                                                                                            |
| **Исходящие потоки данных** | Мастер-данные или их производные представления в Key-Value Storage / Tarantool для ускоренного чтения; данные в другие системы-потребители, если такие интеграции существуют.         |

## 4. Key-Value Storage / Tarantool

| Поле                        | Значение                                                                                                                                                                                                                                                                                                                                                                                                       |
| :-------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | Key-Value Storage / Tarantool                                                                                                                                                                                                                                                                                                                                                                                  |
| **Категория**               | System of Record или инфраструктурное хранилище — зависит от конкретного набора данных; на этой диаграмме лучше обозначить как специализированное хранилище быстрого доступа                                                                                                                                                                                                                                   |
| **Роль в бизнесе**          | Предоставляет быстрый доступ к данным по ключу и может использоваться как самостоятельная база, персистентный кеш или слой хранения метаданных. В VK Teams Tarantool применяется в нескольких сценариях, включая key-value-хранилище, кеширование метаданных и очереди событий. Это не означает, что все показанные на диаграмме данные о поведении пользователей обязательно хранятся в одном таком кластере. |
| **Входящие потоки данных**  | Записи и обновления из MDM; обновления пользовательских данных или событий от других сервисов, если они настроены; запросы на запись и обновление данных от приложений-потребителей.                                                                                                                                                                                                                           |
| **Исходящие потоки данных** | Быстрые ответы на запросы внутренних сервисов; данные для рекомендательных систем и Ads Platform; чтение метаданных и ключевых записей приложениями-потребителями.                                                                                                                                                                                                                                             |

## 5. ERP

| Поле                        | Значение                                                                                                                                                                                                                                                                                         |
| :-------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | ERP WorkSpace                                                                                                                                                                                                                                                                                    |
| **Категория**               | System of Record / System of Engagement (SoE)                                                                                                                                                                                                                                                    |
| **Роль в бизнесе**          | Система планирования ресурсов. Включает в себя набор корпоративных продуктов для коммуникации и совместной работы. VK Teams — корпоративный мессенджер и платформа коммуникаций; VK WorkSpace включает инструменты для совместной работы, в том числе почту, календарь, задачи и другие сервисы. |
| **Входящие потоки данных**  | Данные и метаданные, необходимые для отображения чатов, профилей, файлов и задач; Пользовательские запросы в поддержку                                                                                                                                                                           |
| **Исходящие потоки данных** | Пользовательские запросы к backend-сервисам; сообщения, изменения профилей, файлы, задачи и другие продуктовые данные; события использования, если они собираются для аналитики или рекомендаций.                                                                                                |

## 6. S3 VK Cloud

| Поле                        | Значение                                                                                                                                                                                                                                                                                                                                            |
| :-------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | S3 VK Cloud / Object Storage                                                                                                                                                                                                                                                                                                                        |
| **Категория**               | Сервис хранения объектов; SoR для самих файлов — только в пределах тех приложений, которые используют его как основное хранилище                                                                                                                                                                                                                    |
| **Роль в бизнесе**          | Хранит объекты, например медиафайлы и другие данные, доступные через S3 API. В опубликованном описании VK Cloud Object Storage архитектура разделена на фронты/API, слой метаданных на Tarantool и слой хранения объектов. Это архитектура продукта VK Cloud и не доказывает, что все пользовательские медиа VK.com хранятся именно в этом сервисе. |
| **Входящие потоки данных**  | Запросы на загрузку объектов от клиентских или backend-сервисов через предусмотренный интерфейс; метаданные и параметры хранения; запросы на обновление или удаление объектов от авторизованных потребителей.                                                                                                                                       |
| **Исходящие потоки данных** | Содержимое объектов и ответы на запросы чтения; метаданные и статусы загрузки; ответы об успешном или неуспешном выполнении операций.                                                                                                                                                                                                               |

## 7. Рекомендательные системы

| Поле                        | Значение                                                                                                                                                                                                                                                                                                                                                   |
| :-------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | Рекомендательные системы                                                                                                                                                                                                                                                                                                                                   |
| **Категория**               | System of Insight (SoI), с возможной ролью онлайн-сервиса выдачи рекомендаций                                                                                                                                                                                                                                                                              |
| **Роль в бизнесе**          | Анализируют доступные данные и формируют персонализированные рекомендации контента или других объектов для пользователя. На диаграмме блок получает данные о поведении пользователя и возвращает рекомендации клиенту. Реальная архитектура может включать несколько сервисов: сбор событий, подготовку признаков, обучение моделей и онлайн-ранжирование. |
| **Входящие потоки данных**  | Данные о просмотрах и других действиях пользователя; признаки и справочные данные из внутренних хранилищ; данные о контенте и доступных объектах.                                                                                                                                                                                                          |
| **Исходящие потоки данных** | Ранжированный список рекомендаций для клиента; при наличии рекламной интеграции — сигналы или результаты, используемые другими системами; метрики и результаты работы моделей в аналитический контур.                                                                                                                                                      |

## 8. Ads Platform

| Поле                        | Значение                                                                                                                                                                                                                                                                                                                                                                                                           |
| :-------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | Ads Platform                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Категория**               | System of Engagement (SoE) для рекламной доставки и управления кампаниями; System of Insight (SoI) для аналитических функций — в зависимости от границ блока                                                                                                                                                                                                                                                       |
| **Роль в бизнесе**          | Поддерживает рекламные сценарии: работу с кампаниями, подбор и доставку объявлений, а также измерение результатов. На диаграмме Ads Platform получает данные об аудитории от Tarantool и передаёт рекламные кампании рекомендательным системам. Такое точное направление взаимодействия необходимо подтвердить: публичные описания рекламной инфраструктуры VK не означают, что все компоненты связаны именно так. |
| **Входящие потоки данных**  | Данные об аудитории или признаках пользователя; настройки кампаний, объявления, бюджеты и ограничения; события показов и взаимодействий для подсчёта результатов.                                                                                                                                                                                                                                                  |
| **Исходящие потоки данных** | Рекламные решения или объявления в клиентский продукт через рекламные сервисы; данные о кампаниях и их эффективности в аналитический контур; параметры кампаний или рекламные кандидаты другим компонентам.                                                                                                                                                                                                        |

## 9. DWH / YTsaurus / ClickHouse

| Поле                        | Значение                                                                                                                                                                                                                                                                                  |
| :-------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | DWH / YTsaurus / ClickHouse                                                                                                                                                                                                                                                               |
| **Категория**               | System of Insight (SoI)                                                                                                                                                                                                                                                                   |
| **Роль в бизнесе**          | Аналитический контур для накопления, обработки и анализа больших объёмов данных. YTsaurus — распределённая платформа хранения и обработки данных; ClickHouse может использоваться как аналитический движок. В экосистеме YTsaurus доступен CHYT — ClickHouse, работающий поверх YTsaurus. |
| **Входящие потоки данных**  | Пакетные выгрузки и события из клиентских приложений и backend-сервисов; данные о работе Service Desk; данные о пользовательском поведении и рекламе — если эти события поступают в аналитический контур. Конкретный способ доставки данных на схеме не указан.                           |
| **Исходящие потоки данных** | Подготовленные аналитические наборы и агрегаты в Horizon BI; данные для ad hoc-запросов, исследований и моделей; результаты расчётов для других внутренних потребителей.                                                                                                                  |

## 10. Horizon BI

| Поле                        | Значение                                                                                                                                                                                                                |
| :-------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | Horizon BI                                                                                                                                                                                                              |
| **Категория**               | System of Insight (SoI)                                                                                                                                                                                                 |
| **Роль в бизнесе**          | Слой бизнес-аналитики, который предоставляет пользователям отчёты и дашборды на основе подготовленных данных. В диаграмме он выступает потребителем аналитических данных из DWH и предоставляет результаты менеджменту. |
| **Входящие потоки данных**  | Аналитические наборы, витрины и агрегаты из DWH; определения показателей, параметры отчётов и права доступа — если они предусмотрены используемой BI-платформой.                                                        |
| **Исходящие потоки данных** | Отчёты, дашборды и показатели для менеджмента; экспорт аналитических результатов; уведомления о значениях показателей, если такая функциональность настроена.                                                           |
