# Описание ключевых систем IT-ландшафта Ostrovok.ru

## 1. Клиент / Каталог

| Поле                        | Значение                                                                                                                                                                                                                                                                                                 |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | Клиент / Каталог                                                                                                                                                                                                                                                                                         |
| **Категория**               | System of Engagement (SoE)                                                                                                                                                                                                                                                                               |
| **Роль в бизнесе**          | Пользовательский интерфейс для просмотра каталога отелей, поиска предложений и оформления заказа. Отображает карточки отелей и результаты поиска, инициирует пользовательские действия. В этой модели блок объединяет интерфейс и часть каталожной функциональности; при детализации их стоит разделить. |
| **Входящие потоки данных**  | Результаты поиска от Search Engine; карточки и контент каталога из внутренних сервисов или хранилища; кешированные данные из Redis, если кеш применяется.                                                                                                                                                |
| **Исходящие потоки данных** | HTML, CSS и JS через CDN; Поисковые запросы в Search Engine; запрос на оформление заказа в ERP / систему бронирования; запросы на получение контента;                                                                                                                                                    |

## 2. Search Engine

| Поле                        | Значение                                                                                                                                                                                          |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | Search Engine                                                                                                                                                                                     |
| **Категория**               | System of Engagement (SoE)                                                                                                                                                                        |
| **Роль в бизнесе**          | Выполняет поиск отелей и предложений по параметрам пользователя: направление, даты, количество гостей и другие фильтры. Возвращает результаты, пригодные для отображения в клиентском интерфейсе. |
| **Входящие потоки данных**  | Поисковые запросы от Клиента / Каталога; данные об отелях, тарифах и доступности из каталожных систем и интеграций с поставщиками --- если эти потоки входят в границы рассматриваемой системы.   |
| **Исходящие потоки данных** | Результаты поиска, цены и сведения о доступности в Клиент / Каталог; при необходимости --- телеметрия и события поиска в аналитический контур.                                                    |

## 3. ERP / Система бронирования

| Поле                        | Значение                                                                                                                                                                                                                                                             |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | ERP                                                                                                                                                                                                                                                                  |
| **Категория**               | System of Record (SoR)                                                                                                                                                                                                                                               |
| **Роль в бизнесе**          | Обрабатывает жизненный цикл заказа или бронирования: создание, изменение статуса, подтверждение и отмену. Работа с данными о сервисе, пользователях                                                                                                                  |
| **Входящие потоки данных**  | Запрос на создание заказа от Клиента / Каталога; результаты или статусы оплаты от Платёжного шлюза; запросы по клиентскому заказу от Service Desk / CRM; справочные данные из MDM                                                                                    |
| **Исходящие потоки данных** | Запросы на оплату в Платёжный шлюз; статусы заказа в клиентские или внутренние системы; данные о заказах в CRM / Service Desk при необходимости; данные для аналитического контура; события об изменении заказа или оплаты, если используется событийная интеграция. |

## 4. Платёжный шлюз

| Поле                        | Значение                                                                                                                                                                                                                                                   |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | Платёжный шлюз                                                                                                                                                                                                                                             |
| **Категория**               | Внешняя интеграция / платёжный сервис; категория SoR зависит от того, какие финансовые данные он авторитетно хранит                                                                                                                                        |
| **Роль в бизнесе**          | Передаёт платёжные запросы платёжной инфраструктуре, обрабатывает результаты транзакций и возвращает статус оплаты. Не следует считать его единственным источником истины о состоянии бронирования: статус заказа обычно принадлежит системе бронирования. |
| **Входящие потоки данных**  | Запрос на оплату от ERP / системы бронирования; идентификатор заказа, сумма, валюта и другие необходимые платёжные параметры.                                                                                                                              |
| **Исходящие потоки данных** | Синхронный ответ со статусом операции в ERP / систему бронирования; уведомление об изменении статуса (например, callback/webhook); платёжные данные для сверки и аналитики, если предусмотрена интеграция.                                                 |

## 5. MDM

| Поле                        | Значение                                                                                                                                                |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | MDM (Master Data Management)                                                                                                                            |
| **Категория**               | System of Record (SoR)                                                                                                                                  |
| **Роль в бизнесе**          | Управляет согласованными мастер-данными и справочниками, например идентификаторами и атрибутами сущностей.                                              |
| **Входящие потоки данных**  | Данные из ERP и других операционных систем; записи из внешних источников; запросы на создание или изменение мастер-записей.                             |
| **Исходящие потоки данных** | Согласованные мастер-данные и справочники в ERP, каталог и другие системы-потребители; выгрузки мастер-данных в аналитический контур при необходимости. |

## 6. CRM

| Поле                        | Значение                                                                                                                                                                                                                |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | CRM                                                                                                                                                                                                                     |
| **Категория**               | System of Engagement (SoE); может быть SoR для отдельных данных о взаимодействиях с клиентами                                                                                                                           |
| **Роль в бизнесе**          | Поддерживает работу с клиентскими профилями, историей взаимодействий, обращениями и задачами сотрудников. Точный набор функций зависит от того, какую CRM использует компания и какие процессы в ней ведутся.           |
| **Входящие потоки данных**  | Контактные данные и сведения о клиенте из клиентских или операционных систем; информация о заказах и их статусах из системы бронирования; обращения и результаты работы с ними --- если предусмотрена такая интеграция. |
| **Исходящие потоки данных** | Данные о клиенте или запросе в Service Desk; сведения о взаимодействиях и клиентах в аналитический контур; обновлённые данные в другие системы, если CRM является источником этих атрибутов.                            |

## 7. Service Desk

| Поле                        | Значение                                                                                                                                                                                                      |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | Service Desk                                                                                                                                                                                                  |
| **Категория**               | System of Engagement (SoE)                                                                                                                                                                                    |
| **Роль в бизнесе**          | Предоставляет сотрудникам интерфейс для обработки клиентских обращений и запросов. Может помогать находить сведения о клиенте и заказе, но не обязательно является владельцем этих данных.                    |
| **Входящие потоки данных**  | Новые обращения от клиентов или сотрудников; данные о клиенте и заказе из CRM и системы бронирования; уведомления о статусах обращения, если они поступают из других систем.                                  |
| **Исходящие потоки данных** | Запросы к CRM и системе бронирования для получения сведений о клиенте и заказе; обновления статуса обращения; данные об обращениях и времени обработки в аналитический контур, если такая выгрузка настроена. |

## 8. Data Quality Platform (Soda Core)

| Поле                        | Значение                                                                                                                                                                                                     |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Название системы**        | Data Quality Platform / Soda Core                                                                                                                                                                            |
| **Категория**               | System of Insight (SoI), вспомогательная платформа качества данных                                                                                                                                           |
| **Роль в бизнесе**          | Проверяет качество наборов данных по заданным правилам: полноту, допустимые значения, уникальность и другие ограничения. Помогает обнаруживать ошибки до использования данных в отчётности.                  |
| **Входящие потоки данных**  | Наборы данных из операционных источников, промежуточных слоёв или DWH; конфигурации проверок и пороговые значения. Конкретные источники зависят от реализации пайплайнов.                                    |
| **Исходящие потоки данных** | Результаты проверок, метрики качества, предупреждения и сведения о нарушениях; сигналы для остановки или продолжения пайплайна, если такая логика интегрирована; отчёты о качестве для ответственных команд. |

## 9. DWH / Apache Ozone

| Поле                        | Значение                                                                                                                                                                                    |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | DWH / Apache Ozone                                                                                                                                                                          |
| **Категория**               | System of Insight (SoI)                                                                                                                                                                     |
| **Роль в бизнесе**          | Аналитический контур для накопления и обработки данных из нескольких источников.                                                                                                            |
| **Входящие потоки данных**  | Пакетные выгрузки из ERP, CRM и других операционных систем; подготовленные наборы данных из ETL/ELT-процессов; результаты проверок качества или данные, прошедшие соответствующие проверки. |
| **Исходящие потоки данных** | Подготовленные аналитические наборы данных для BI Analytics; данные для ad hoc-анализа и вычислительных задач; при необходимости --- агрегаты и витрины для других внутренних потребителей. |

## 10. BI Analytics

| Поле                        | Значение                                                                                                                                                                                                                        |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название системы**        | BI Analytics                                                                                                                                                                                                                    |
| **Категория**               | System of Insight (SoI)                                                                                                                                                                                                         |
| **Роль в бизнесе**          | Предоставляет отчёты, дашборды и показатели для анализа работы бизнеса и принятия управленческих решений. Обычно потребляет подготовленные данные и не должна выступать источником операционных записей о заказах или платежах. |
| **Входящие потоки данных**  | Аналитические наборы, витрины и агрегаты из DWH; определения метрик и прав доступа; при необходимости --- справочники и бизнес-правила.                                                                                         |
| **Исходящие потоки данных** | Отчёты и дашборды для менеджмента; аналитические результаты для бизнес-команд; экспорт данных и уведомления о показателях, если соответствующие функции настроены.                                                              |
